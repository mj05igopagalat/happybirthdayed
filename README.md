# Raizza's Birthday Greeting

A small, phone-friendly birthday page for Raizza San Juan. The main birthday window features an animated cake and confetti, with a button that opens a heartfelt letter. It also includes a selected gallery of photos from `images/` and supports reduced-motion preferences. It can be opened locally or published with GitHub Pages.

## Personalize it

- To add another photo, put it in `images/` and add a matching `<figure>` to the gallery in `index.html`.
- The music button plays `music/Maligayang bati sa iyong kaarawan (Roblox).mp3`. Keep that file in the `music` folder when publishing the page.
- Edit the birthday message in `index.html` if you want to add your own words.

## Open it locally

Open `index.html` in a web browser. An internet connection is needed for the decorative web fonts; the page uses fallback fonts otherwise.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `raizza-birthday`.
2. Upload the contents of this folder to the repository's root (not the folder itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. After GitHub Pages finishes publishing, open the URL shown in the Pages settings.

Only add photos or music that Raizza is happy to have shared publicly.
